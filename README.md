# Java Console ATM System

## Overview
A console-based banking application developed to demonstrate core Object-Oriented Programming (OOP) principles in Java. This system allows users to perform standard banking operations like withdrawals, deposits, and fund transfers in a secure, authenticated environment.

## Features
* **User Authentication:** Secure login using Account Number and PIN.
* **Transaction Handling:** Support for Deposit, Withdrawal, and Money Transfer.
* **Exception Handling:** Custom exceptions for insufficient funds and invalid inputs.
* **OOP Implementation:** Utilizes Abstraction, Interfaces, Encapsulation, and Polymorphism.

## Tech Stack
* Java (JDK 17+)
* Concepts: OOPs, Exception Handling, Collection Framework (HashMap)

## How to Run
1. Clone the repository.
2. Compile: `javac Main.java`
3. Run: `java Main`
4. Use Test Credentials: Account `12345`, PIN `1111`.
